# Loops

if else while for

## if

Use braces if you want to run multiple statement

```bash
$awk '{
if ($1 > 15)
{
    x = $1 * 3
    print x
}
}' my_file
```

## else

Use braces if you want to run multiple statement

```bash
$awk '{
if ($1 > 15)
{
    x = $1 * 3
    print x
} else
        {
        x = $1 / 2
        print x
}}' my_file
```

OR write it all on one line, separated by semicolon

```bash
$awk ‘{if ($1 > 15) print $1 * 3; else print $1 / 2}’ my_file
```

## while

Iterates over data with a condition

For example, I've a file **class_grades** containing numbers:

```bash
$awk '{
tot = 0
i = 1
while (i < 5)
    {
    tot += $i
    if (i == 3)
    break   #exit loop using `break`
    i++
    }
average = tot / 3
print "Average is:",average
}' class_grades
```

## for

```bash
$awk '{
total = 0
for (var = 1; var < 5; var++)
    {
    total += $var
    }
avg = total / 3
print "Average:",avg
}' class_grades
```
