# SOLUTIONS FROM **sed** lab

+ Check if an old temporary file exists called **employee.bak** and if so, then delete this

```bash
if [ -a employee.bak ]; 
    then rm -f employee.bak 
    fi
```

+ Check if /.bashrc is a regular file 

```bash
if [ -f ~./bashrc ]; then
echo "Hello there $USER, this is a regular file"
fi
```

or using a single line of code:
```bash
[ -f ~/sample.txt ] && echo “File exists.” || touch ~/sample.txt
```

+ Using a **for** loop to make a backup copy of each **.txt** file 

```bash
$ls *.txt > textlist
$ for i in `cat textlist`;
do cp "$i" "$i.backup";
done
```
