# 05. EXER Add new records

# EXERCISE

Write a script that can be used to add a new record (employees details) to your **employee.txt** file 

## TIPS

Think about this logically: 
- 1st check if the file exists and maybe do you want to create it if it’s not there? Do you want to use to receive error messages? Customised feedback? 
- Then you want to give appropriate variable names in order to the positional parameter, the 1st parameter being the employee’s ID, the second their name, the third their position in the company. 4th the dept they belong to and finally, 5th the expenses they claimed. 
- Whats next? Time to take the details in and append them to your **employee.txt** file

ERROR CHECKING: 

Error checking is an **absolute MUST** especially when you're taking user input into a system to ensure that the expected input is in the expected format i.e. email addresses, phone numbers, postcodes etc. are all in the expected format

![Error Checking](./img/error.png)

- you could welcome the user by their name, check and only continue that the the number of arguments passed in by them is =5 and append to **employee.txt** only if this is the case or else indicate to the user it’s the incorrect number of args and try again. 
- ask the user when they've entered one new record if they wish to add more or return to the main screen/exit the script.
- Error messages could be used at any stage to, say, confirm to the user if they want to append details the file, or at the end to show them what they have entered and confirm that the details entered are correct. 
- Will you check for duplicates? What action will the script take if there are? What's the unique record identifier?
- make best use of friendly easy-to-use user input, output to screen and you'll need to use loops. 

## SAMPLE SOLUTION

Your code could loop until all pieces of required data from the user have been entered

```bash
count=0
while [ $count -lt 4 ]
do
   if [ $count -eq 0 ]
# Don't forget that in an if statement,  we need a space after the opening and the closing brace. Otherwise things do not work. 
   then
      echo "Please enter contacts Name : "
      read name
      # Checks the entered name is not blank, otherwise a warning is issue and user asked to re-enter
      if ! [ -z "${name}" ]
      then
        count=$((count+1))
      else
        echo "Warning: You cannot enter a blank name"
      fi
   fi
```

You could also include use of error checking i.e that eircode is not blank but also in correct format, that email address is not blank but also in correct format, maybe consider piping to grep to check for the @ symbol etc.
