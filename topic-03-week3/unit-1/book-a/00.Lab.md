## Addition

Computes addition of two numbers provided as operands.

```bash
#!/bin/bash
x=$(( 15 + 8 ))
echo $x
``` 
or 

```bash
#!/bin/bash
x=`expr 15 + 8`
echo $x
```

## Subtraction

Computes subtraction of second operand from first.

```bash
#!/bin/bash
x=$(( 15 - 8 ))
echo $x
```
or

```bash
#!/bin/bash
x=`expr 15 - 8`
echo $x
```

## Multiplication

Computes the product of two operands provided.

```bash
#!/bin/bash
x=$(( 15 * 8 ))
echo $x
```
or

```bash
#!/bin/bash
x=`expr 15 * 8`
echo $x
```

## Division

Computes the division of first operand by second operand and returns quotient.

```bash
#!/bin/bash
x=$(( 15 / 8 ))
echo $x
```

or

```bash
#!/bin/bash
x=`expr 15 / 8`
echo $x
```

## Incrementing/Decrementing 

```bash
#!/bin/bash 
x=2
(( x += 5 )) # x -= 5 to decrement
echo $x
```
