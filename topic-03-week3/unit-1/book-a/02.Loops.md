# for

Amend the basic **for** loop from the class notes  to include a **for**, including an **if** statement and **break**

1. Look through this **for** code below: what is the expected output?

```bash
for i in {1..5}; 
do
  for j in {1..3};  
    do
        if [[ $j -eq 2 ]]; then
        break
        fi
    echo "The value of j is: $j"
    done
  echo "The value of i is: $i"
done
echo All Done!
```
