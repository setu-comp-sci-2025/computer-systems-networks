# 04. sed

sed editor · find and replace 

For this lab, download [Distros.txt file](./archives/archive.zip), a space separated text file, and try the following commands:

- Print lines 7-9 inclusive:
```bash
$ sed -n '7,9p' distros.txt
```

- Search for a pattern and print it:

```bash
$ sed -n '/SUSE/p' distros.txt # print lines matched by "SUSE"
```

- Negate the above search pattern:

```bash
$ sed -n '/SUSE/!p' distros.txt #except the ones matched by X
```

# PRACTICE using **sed**

Make a copy of the **distros.txt** file, named **tempdistros.txt** and practice **d**eleting sections of the file

```bash
$ sed '1d' tempdistros.txt #deletes 1st line
$ sed '$d' tempdistros.txt #deletes last line
$ sed '3,6d' tempdistros.txt #deletes lines 3, 4, 5 and 6
$ sed '1!d' tempdistros.txt #deletes all EXCEPT 1st line
$ sed '$!d' tempdistros.txt #deletes all EXCEPT last line
$ sed '3,6!d' tempdistros.txt #deletes all EXCEPT lines 3, 4, 5 and 6
$ sed '1d;$d' tempdistros.txt #deletes 1st and last lines
$ sed '/^$/d' tempdistros.txt #Delete empty lines or blank lines. ^$ indicates to delete empty lines. However, it doesn't remove the lines that contain spaces.
$ sed '/^u/d' tempdistros.txt #del lines starting with specified character 
$ sed '/u$/d' tempdistros.txt #del lines ending with specified character
$ sed '/^[A-Z]*$/d' tempdistros.txt #Del lines ending in upper case
```
