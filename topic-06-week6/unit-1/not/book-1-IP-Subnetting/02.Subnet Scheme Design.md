# Part1: FLSM - Design

### Fixed Length Subnet Mask

You are tasked to install a new network for a local SME. You must create multiple subnets out of the **172.16.50.0/24** network address space to meet the following requirements:
+ The first subnet is the *Workstation-LAN* network. You need a **minimum of 50 host IP addresses**
+ The second subnet is the *IoT-LAN* network. You need a **minimum of 40 host IP addresses.**
+ You also need at l**east two additional unused subnets** for future network expansion.

**Note: All of the subnet masks should be the same length(Fixed Length Subnet Mask).**

## Determine Network Design Requirements

Answer the following questions to help you design the correct subnet scheme

**Question:** How many host addresses are needed in the largest required subnet?

**Question:** What is the minimum number of subnets required?

Remember, to subnet a network, bits from the host portion of the original network mask are "borrowed" for subnet bits. The number of subnet bits defines the number of subnets and the number of hosts.

## Determine possible subnet masks

 For the 172.16.50.0/24 network, select the optimum subnet mask. Use a subnet table or other tool to do this.

![Subnet Masks](./img/subnets.png)

**Hint:** Remember that the number of host bits (to the power of 2) defines the number of hosts per subnet (minus 2), and the number of subnet bits (to the power of two) defines the number of subnets. The subnet bits are the bits that have been borrowed beyond the original network mask of /24. The /24 is the prefix notation and corresponds to a dotted decimal mask of 255.255.255.0.
