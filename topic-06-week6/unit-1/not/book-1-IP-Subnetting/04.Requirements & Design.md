# Part2: VLSM -  Design

Variable Length Subnet Mask (VLSM) avoids wasting IP addresses. With VLSM, a network is subnetted and then re-subnetted. This process can be repeated multiple times to create subnets of various sizes based on the number of hosts required in each subnet. **Effective use of VLSM requires address planning.**

In this exercise, you will use the **192.168.33.128/25** network address as the base network to develop an address scheme for the network displayed in the topology diagram below. VLSM is used to meet the IPv4 addressing requirements.
