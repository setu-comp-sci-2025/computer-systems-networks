## Connect the LANs

You will now add the devices and link them as indicated to complete the SME topology consisting of 2 LANS, workstation-LAN and IoT-LAN.

![SME Logical Topology](./img/topology.png)



Connect the missing devices as indicated in the above topology and using the following criteria.  

+ Connect Switch1 to port port Fa1/0 on the SME Router. This is for the Workstation-LAN
+ Connect Switch2 to port Fa2/0 on the SME Router. This is for the IoT-LAN
+ Connect Port0 on the Access Point to Switch2
+ Connect Ethernet0 on Office PC to Switch1


## Determine IP Addresses

Fill in the missing values  in the below IP Addressing based on the following instructions:

+ **Assign the 1st subnet to the Workstation-LAN**
  + Use the **first  host address** for the SME router on port Fa1/0
  + Use the **second host address** for Office PC. Make sure to assign the correct default gateway address for the PC.


+ **Assign the 2nd subnet to the IoT-LAN**
  + Use the **first host address** for the SME router on port Fa2/0
  + Use the **last host address** for the Temperature Monitor. Make sure to assign a default gateway address.

## Configure Devices

Configure settings on the end devices and router using the Addressing Table from the previous Step: 

### Temperature Monitor

+ Double Click the device in the Logical Workspace and select the *config* tab. 

+ Select Setting and enter the the correct Default Gateway.

+ Select Wireless0 and enter the Static IP address and subnet mask from the table.  

  ![](./img/wireless.png)

### SME Router

+ Double Click the SME Router in the Logical Workspace and . 

  ### Using CLI (more realistic)

+ Select the *CLI* tab. Review last weeks lab and use the correct CLI commands to assign the correct IP config to Fa0/0 and Fa1/0.

  **OR**

  ### Using Config Tab (probably handier!)

+ Select the *Config* tab. Then select the interface you want to configure and enter the values for IP Address and Subnet mask. Make sure to turn the interface on also! The following image shows FastEthernet1/0 (Fa1/0).

![IP Address Table](./img/fa00.png)

+ Make sure to configure both Fa1/0 and Fa2/0 (and don't forget to switch the the ports on!).
