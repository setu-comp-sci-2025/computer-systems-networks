# **printf** for snazzier formatting

```bash
$awk 'BEGIN { printf "%-10s %s\n", “Name”, “Dept” } { printf "%-10s %s\n", “______”, “_____” } { printf "%-10s %s\n", $2, $3 }' employee.txt
```

where this will return a padding of 10 for **Name** and zero padding for **Dept**.
