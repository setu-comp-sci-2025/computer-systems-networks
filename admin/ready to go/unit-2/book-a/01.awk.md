# Field Separators/Delimiters

A space is the default field separator

You can change the default **space** field separator so, say you were working with a file whose fields are *colon* separated:

$awk -F ":" '{print $1}'

So for `/etc/passwd`, try to print the 1st, 6th and 7th fields of this colon separated file:

```bash
$awk -F ":" '{print $1, $6, $7}' filename
```

Maybe this would look neater if the output was separated by a tab mark:

```bash
$awk -F ":" '{print $1"\t", $6"\t", $7}' filename
```

# **grep** and then **awk** to filter

1. Suppose you wish to search for (case insensitive) "Caroline" in **employee.txt**, you would use:

```bash
$ grep -i Caroline employee.txt
```

PROBLEM:

This returns *all of the columns* associated with "Caroline".

To further filter this to only return back particular field(s) i.e. their employee number and name only, you could use **awk** to specify particular column(s):

```bash
$ grep -i Caroline employee.txt | awk '{print $1, $2}'
```

2. Extracting using **awk**

You can extract numeric values from any string using **awk**:

```bash
$echo 'caroline1234' | awk -F'[^0-9]*' '$0=$2'
```

But you can use **grep** which works great in extracting content and in this case using **grep** is more preferably 

```bash
$echo 'caroline1234', 'frank5678' | grep -o '[0-9]\+'
```
where 
- the **[0-9]** indicates a range of 0-9
- the **\+** means the preceding character must exist one or more times
- **man grep** to see what the **-o** is used for

# Variables 

Let's say the eighth column of **employee.txt** file stores the employee's email address. 

You want to extract only this email and store as the **empEmail** variable. 

Then you wanted to run the basic Linux **mail** command to email these extracted and stored (as variable **empEmail**) email addresses:

```bash
$ empEmail=`grep -i Caroline employee.txt | awk '{print $8}'`   
mail $empEmail
```

+ where **mail** is a simple command-line utility that allows users to send emails from the command line.
