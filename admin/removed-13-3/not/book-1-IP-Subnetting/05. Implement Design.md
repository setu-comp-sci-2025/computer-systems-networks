+ Configure **PC-BR1**  with a **valid IP addresses and default gateway** for network BR1 LAN. (hint: Remember, the first valid host address and default gateway is on Router BR1 interface Fa0/0). 

+ Configure **PC-BR2**  with a **valid IP addresses and default gateway** for network BR2 LAN. (hint: Remember, the first valid host address and default gateway is on Router BR2 interface Fa0/0). 

+ Check connectivity between PC-BR1 and PC-BR2. This will complete the activity.
