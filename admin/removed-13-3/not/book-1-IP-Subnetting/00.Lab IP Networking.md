# IPv4 Subnetting

Design a Subnetting Scheme · Implement Subnet · Test  connectivity

 You will subnet a Small/Medium size business' network into multiple subnets. You will design the subnet scheme based on the number of host computers required in each subnet, as well as other network considerations, like future network host expansion.
After you have created a subnetting scheme, you will configure host devices and router interfaces.
After the network devices and host PCs have been configured, you will test for network connectivity.

## Objectives

In this lab, you will:

- Design a IPv4 Network Fixed Mask Length Subnetting Scheme
- Configure the Devices to implement the subnetting scheme
- Test and validate the connectivity between different networks and subnets.
- Design a IPv4 Network Varia Mask Length Subnetting Scheme
