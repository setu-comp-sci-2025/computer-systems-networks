# Router IP Configuration - SOLUTION

Router Configuration · Device IP Configuration · Test  connectivity

IoT devices can be a security concern and have been used in [several hacking events](https://cisomag.eccouncil.org/hackers-can-steal-your-identity-and-bank-details-from-a-coffee-machine/) in domestic environments. 

In this lab you will enhance the home network example from last week to include 2 separate networks; one for IOT and "Guest Devices" and the other for your Home Office. This allows you to separate less secure devices from home office network.

## Objectives

In this lab, you will:

- Complete Network Documentation
- Use IOS to check existing Router configurations
- Configure Router1 interfaces
- Configure end devices with static IP addresses
- Test and validate the connectivity.
