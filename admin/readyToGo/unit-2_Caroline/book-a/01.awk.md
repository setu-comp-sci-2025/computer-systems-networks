# Field Separators/Delimiters

A space is the default field separator

You can change the default **space** field separator so, say you were working with a file whose fields are *colon* separated:

- So for `/etc/passwd`, to print the 1st, 6th and 7th fields of this colon separated file:

```bash
$awk -F ":" '{print $1, $6, $7}' /etc/passwd
```

Maybe this would look neater if the output was separated by a tab mark:

```bash
$awk -F ":" '{print $1"\t", $6"\t", $7}' /etc/passwd
```
or
```bash
$awk -F ":" '{print $1"\t" $6"\t" $7}' /etc/passwd | column -t
```
where

- when you pipe (**|**) that into **column -t**, it aligns everything into clean columns:

**column** is a command-line utility that formats text input into neatly aligned columns.

The **-t** option tells column to create a table by determining the number of columns and aligning them based on whitespace (e.g. tabs or spaces).

# **grep** and then **awk** to filter

Suppose you wish to search for "Caroline" (case insensitive) in **employee.txt**, you would use:

```bash
$ grep -i Caroline employee.txt
```

PROBLEM:

This returns *all of the columns* associated with "Caroline".

Further filter this:
-  to only return back their employee number and name only 

Use **awk** to specify particular column(s):

```bash
$ grep -i Caroline employee.txt | awk '{print $1, $2}'
```

2. Extracting numeric values using **awk**

The below command extracts the first numeric part of a string by:

- Splitting the string on non-digit characters

- Replacing the full line $0 with the second field $2

```bash
$echo 'caroline1234' | awk -F'[^0-9]*' '$0=$2'
```

But you can use **grep** which works great in extracting content and in this case using **grep** is more preferably 

```bash
$echo 'caroline1234', 'frank5678' | grep -o '[0-9]\+'
```
where 
- the **[0-9]** indicates a range of 0-9
- the **\+** means the preceding character must exist one or more times
- **man grep** to see what the **-o** is used for
