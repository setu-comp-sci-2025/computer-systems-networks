# Extract and filter

## EXERCISES

1. Allow the user input the name of a new employee. The system is to then return their expenses:

```bash
The expenses recorded for XXX are: $YYY
```
i.e.
```bash
The expenses recorded for Caroline are: €5500
```

where

- **XXX** is the name of the employee the user has entered/wishes to search up

- **YYY** is their associated column in the **employee.txt** file

*TIPS* 

Consider 
+ **read**ing in the search term (i.e. the employee's name) from the user
+ set an **expenses** variable 
+ **grep** the name entered and 
+ pipe this to **awk** to print the associated column

2. You now want to output the name of the employee who has the maximum expenses in the **employee.txt** file

*TIPS*

+ you can use **sort** command to sort the Xth column numerically and in reverse order so you can get the highest value on the top.

+ Then you can pipe it to the **head** command to get the first row only.

+ Finally, you can use **awk** to print the expenses column.
