## Thingspeak HTTP API

To send temperature data from a Raspberry Pi to a ThingSpeak channel, you can read the sensor data and make HTTP requests to update your ThingSpeak channel. 

### Data API

Create new folder called **week 11-lab2**

- ```
  mkdir ~/week11-lab2/
  cd ~/week11-lab2/
  python -m venv .venv --system-site-packages
  ```

- Activate the venv:

  ```
  source .venv/bin/activate
  ```



+ In ``week11-lab2`` folder, create a new python script called ``thingspeak_data_http.py`` with the following content:

```python
from sense_hat import SenseHat
import requests
import time

sense = SenseHat()

# ThingSpeak settings
THINGSPEAK_WRITE_API_KEY = os.getenv("TS_WRITE_KEY", "<PASTE_WRITE_KEY_HERE>")
THINGSPEAK_CHANNEL_URL = "https://api.thingspeak.com/update"

# Function to send data to ThingSpeak
def send_to_thingspeak(temperature):
    payload = {
        'api_key': THINGSPEAK_WRITE_API_KEY,
        'field1': temperature
    }
  
    response = requests.get(THINGSPEAK_CHANNEL_URL, params=payload)

    if response.status_code == 200:
        print("Data sent to ThingSpeak.")
    else:
        print(f"Failed to send data. Status code: {response.status_code}")
   


while True:
    # Read temperature and humidity from Sense HAT
    temperature = round(sense.get_temperature(),2)
    
    print(f"Temperature: {temperature} C")

    # Send the data to ThingSpeak
    send_to_thingspeak(temperature)

    # Wait before the next reading (ThingSpeak recommends 15-second intervals for free accounts)
    time.sleep(15)


```

The above program sends a HTTP GET request to update ThingSpeak fields. The `field1`  correspond to the temperature in the ThingSpeak channel. The ``while`` loop runs every 15 seconds to meet ThingSpeak’s recommended minimum update interval for free accounts.

+ **Replace `YOUR_THINGSPEAK_WRITE_API_KEY`** with your actual Write API Key from your ThingSpeak channel.

+ Run the program:

```
export TS_WRITE_KEY=YOUR_THINGSPEAK_WRITE_API_KEY
python thingspeak_data_http.py
```

After running the script, you should see your temperature data updating in real-time on your ThingSpeak channel.
