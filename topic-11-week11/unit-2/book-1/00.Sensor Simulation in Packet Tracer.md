# OPTIONAL: Sensor Simulation in Packet Tracer

Using Cisco Packet Tracer to simulate sensors provides an easy and quick way to prototype and test IoT systems. Packet Tracer allows you to simulate devices, including IoT sensors, without the need for physical hardware. By configuring sensors to send data via the User Datagram Protocol (UDP), users can replicate real-world scenarios where sensors transmit data to servers or other devices. This approach can be used to rapidly develop and test projects  before deploying real sensors.

  

## Equipment

+ Raspberry Pi 3/4 with SenseHAT
+ Mobile Phone (Android/iPhone)
+ Blynk Account with Free tier access
+ Packet Tracer
