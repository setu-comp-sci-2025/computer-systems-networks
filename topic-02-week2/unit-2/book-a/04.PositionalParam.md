# 04. Positional Parameters

$0 · $# · $1

# $0

This variable contains the name of the script itself

```bash
#!/bin/bash
echo "Hello you’re looking at your file called $0"
```
# $#

This variable contains the number of arguments passed to the script on the command line:

```bash
$nano args
echo There were $# arguments passed
echo The first arg was $1 The second arg was $2 The third arg was $3
```

- Execute the script passing in sample arguments, such as **a**, **b** and **c**
- Execute the script passing in sample arguments, such as **abc**
- Execute the script passing in only two sample arguments
- Execute the script passing in zero sample arguments

# $1, $2 etc.

These are variables that read the first command line argument with **$1**, the second command line argument with **$2** etc.

```bash
$nano findproc
ps -ef | grep $1
```

Save, exit and execute **findproc**

Execute again passing your username as the argument and see the results.

- The **ps** reports a snapshot of all current processes
- -e selects all processes
- -f sees full format listing. Also see **man ps**
- grep searches for patterns

# $@, $*

- **$@** means all parameters (but not $0 which is the command given)


- $* references all the arguments passed to a program

```bash
#!/bin/bash
echo "There were $# variables passed "
echo "All arguments passed can be viewed using the \$* variable E.G. $* "
```

# $? for Exit Codes

```bash
$cat employee.txt
$ echo $?
```

The command was successful. The file exists and there are no errors in reading the file or writing it to the terminal. 
The exit code is therefore 0.

```bash
$cat nofile.txt
$ echo $?
```

the file does not exist.
The exit code is therefore 1 as the operation was not successful.

To use exit codes in scripts an **if statement** can be used to see if an operation was successful.

```bash
#!/bin/bash

cat nofile.txt 

if [ $? -eq 0 ]
then
  echo "The script ran ok"
  exit 0
else
  echo "The script failed" >&2
  exit 1
fi
```

To suppress the error message any output to standard error is sent to `/dev/null` using `2>/dev/null`.
