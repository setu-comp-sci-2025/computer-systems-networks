## Redirecting using **<**

Use the **employee.txt** file as the STDIN for the **sort** command  (by default this will sort by the first columm)

```bash
$ sort < employee.txt
``` 

## Redirecting STDOUT using **>**

Use the **employee.txt** file as the STDIN for the **sort** command, this time sending the STDOUT (i.e. the sorted list) into a new **SortedEmployees.txt** file


## Redirecting STDOUT and STDERR using &>

Use **2>&1** syntax to redirect standard error to the same location as standard output 

```bash
$ls /usr/bin > command.txt 2>&1
```
where:
 - **ls /usr/bin** is the command run
- **> command.txt** redirects the output of the **ls** command into the text file
- **2>&1** sends the output of the FD2 (stderr) to the same location as the FD1 (stdout)


This could be re-written more streamlined as 
```bash
$ls /usr/bin ______ command.txt <<fill in the blank>>
```
