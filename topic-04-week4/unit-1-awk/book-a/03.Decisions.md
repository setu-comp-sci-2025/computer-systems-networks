# Loops

if else while for

## if

```bash
# print $1 * 3 when the first field is greater than 15:
awk '{
    if ($1 > 15){
        print = $1 * 3
    }
}' my_file
```

## else

Use braces if you want to run multiple statement

- Check if the first field ($1) is greater than 15.

    - If so, it multiplies it by 3.

    - Otherwise, it divides it by 2.

- Then print the result

```bash
awk '{
    if ($1 > 15)
        print $1 * 3
    else
        print $1 / 2
    }' my_file

```
## while

Iterates over data with a condition

For example, I've a file **class_grades** containing numbers:

```bash
awk '{
    tot = 0
    i = 1
    while (i < 5) {
        tot += $i
        if (i == 3)
            break   # exit loop when i == 3
        i++
    }
    average = tot / 3
    print "Average is:", average
}' class_grades.txt
```

## for

A **for** loop can yield cleaner syntax than the **while** loop above to get average of first three columns

```bash
awk '{
    total = 0
    for (var = 1; var <= 3; var++) {
        total += $var
    }
    avg = total / 3 
#Works only if every line has at least 3 fields.
    print "Average:", avg
}' class_grades

```

it might be nice to consider adding a BEGIN to include a header

BEGIN { 
    print "Average of first 3 grades:" 
}
