# SOLUTIONS FROM **sed** lab

+ Check if an old temporary file exists called **employee.bak** and if so, then delete this

```bash
if [ -a employee.bak ]; 
    then rm -f employee.bak 
    fi
```

+ Check if /.bashrc is a regular file 

```bash
if [ -f "$HOME/.bashrc" ]; then
echo "Hello there $(whoami), this is a regular file"
fi
```

Print message if file exists, otherwise create it:
```bash
file="$HOME/sample.txt"

if [ -f "$file" ]; then
  echo "File exists."
else
  touch "$file"
fi
```

+ Using a **for** loop to make a backup copy of each **.txt** file 

```bash
for i in *.txt; do
    cp "$i" "$i.backup"
done
```
