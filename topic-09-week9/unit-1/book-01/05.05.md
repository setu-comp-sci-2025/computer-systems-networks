## Create a Systemd Service

It would be nice if the web API started up automatically when the RPi boots. You can use a `systemd` service to automatically start a Flask API located at `~/week9-lab1` on a Raspberry Pi.

The following assumes a RPi configuration and installation from the previous labs. You may need to alter the configuration file if you have a bespoke/different RPi set up

## Create a Systemd Service File

+ Open a new service file in the `/etc/systemd/system/` directory:

```bash
sudo nano /etc/systemd/system/flask_api.service
```

+ Add the following configuration to the file, **replacing YOUR_USER_NAME with the user name you use to connect to your RPi**:

```ini
[Unit]
Description=Flask API Service
After=network.target

[Service]
User=YOUR_USER_NAME
WorkingDirectory=/home/YOUR_USER_NAME/week9-lab1

# Use the Python interpreter from the virtual environment
ExecStart=/home/YOUR_USER_NAME/week9-lab1/.venv/bin/python /home/YOUR_USER_NAME/week9-lab1/sense_api.py

# Automatically restart on failure
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

- Ensure that `WorkingDirectory` points to the directory where the Flask API is located (`/home/YOUR_USER_NAME/week9-lab1` is you followed the lab exactly).
- **`ExecStart`** points directly to the `python` executable *inside your virtual environment*, so dependencies are found automatically. If you are using a environment different to the previous labs, adjust `ExecStart` to point to wherever the Python executable within that environment.
- 

## Reload systemd

Reload `systemd` so it recognises the new service:

```bash
sudo systemctl daemon-reload
```

## Enable the Flask Service to Start on Boot

Enable the service to start automatically whenever the Raspberry Pi boots:

```bash
sudo systemctl enable flask_api.service
```

## Start the Flask Service

Start the service immediately to test it:

```bash
sudo systemctl start flask_api.service
```

## Check the Status of the Service

Verify that the service is running correctly:

```bash
sudo systemctl status flask_api.service
```

If everything is set up correctly, the Flask API located in `~/week9-lab1` should start automatically on boot and can be manually controlled using systemd commands.
