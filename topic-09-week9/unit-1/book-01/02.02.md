# Device Web Page Interface

Many consumer devices, in addition to an API, will also provide a html based interface that gives an overview of the device and an API description. The following example is for a connected comsumer device: 

![Example Device Interface](./img/rob.png)



For our device (the RPi) we can use the base route ('/') to provide this, reusing some of the HTML templating skills from last semester...

### HTML Template Rendering

Flask provides for HTML template rendering using the ``render_template`` module. 

+ In the file *sense_api.py*, update the ***flask***  import statement to include **render_template** as follows:

~~~pyhton
from flask import Flask, request, render_template
~~~

### Environment HTML Template

+ in *week9-lab1*, create a new folder called ***templates***.
+ In templates, create a new file called ***status.html*** with the following contents. 

~~~html
<!doctype html>

<html>

<head>
    <title>Device1 Environment Data</title>
    <link href="https://mattduck.github.io/generic-css/css/generic-light.min.css" rel="stylesheet" type="text/css"/>
</head>

<body>
    <h1>Device1 Environment Data Summary</h1>

    <h2>Temperature</h2>
    <p><strong>Celcius:</strong> {{ celcius }}</p>
    <p><strong>Fahrenheit:</strong> {{ fahrenheit }}</p>

    <h2>API Description</h2>
    <p>For use by developers...</p>
    <table>
        <thead>
            <tr>
                <th>Resource/Path</th>
                <th>GET</th>
                <th>POST</th>
            </tr>
        </thead>
        <tbody>
            <tr>
                <td>/sensehat/environment</td>
                <td>Current environment data</td>
                <td>Not Used</td>
            </tr>
            <tr>
                <td>/sensehat/light</td>
                <td>Current light state(i.e. on/off)</td>
                <td>Change light state using status query parameter. <br>
                    e.g. curl -X POST http://YOUR_PI_IP:5000/sensehat/light?state=on</td>
            </tr>
        </tbody>
    </table>
</body>

</html>
~~~

Notice how the templating engine uses the ``{{celcius}}`` and ``{{fahrenheit}}`` used as a placeholder for dynamic values, allowing variables to be injected into an HTML page. 

### Implement the base route

+ Add the following code to *sense_api.py* 

  ~~~python
  @app.route('/') 
  def index():
      celcius = round(sense.temperature, 2)
      fahrenheit = round(1.8 * celcius + 32, 2)
      return render_template('status.html', celcius=celcius, fahrenheit=fahrenheit)
  
  ~~~

This function will return the status.html template, rendered with temperature data from the SenseHat. 
Notice how `celcius` and `fahrenheit` are passed to `render_template()`, and Flask will replace `{{ celcius }}` and `{{ fahrenheit }}` in `temperature.html` with these values.
