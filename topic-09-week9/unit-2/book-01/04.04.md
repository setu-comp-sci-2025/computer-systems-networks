## Run as a systemd Service

Create a new service file:

```
sudo nano /etc/systemd/system/sense-mqtt.service
```

- Add the following configuration to the file, **replacing YOUR_USER_NAME with the user name you use to connect to your RPi**:

```cmd
[Unit]
Description=MQTT SenseHAT Service
After=network.target

[Service]
User=YOUR_USER_NAME
WorkingDirectory=/home/YOUR_USER_NAME/week9-lab2

# Use the Python interpreter from the virtual environment
ExecStart=/home/YOUR_USER_NAME/week9-lab2/.venv/bin/python /home/YOUR_USER_NAME/week9-lab2/sense_mqtt.py

# Automatically restart on failure
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Save and exit.

Then run:

```
sudo systemctl daemon-reload
sudo systemctl start sense-mqtt.service
sudo systemctl enable sense-mqtt.service
```

Check that it’s running:

```
sudo systemctl status sense-mqtt.service
```

------

## Observe and Debug

View logs in real time:

```
journalctl -u sense-mqtt.service -f
```

If your service fails, check for:

- Typos in the Python path or file name
- MQTT connection issues (ensure the Pi is online)
- Indentation errors in the `.service` file
