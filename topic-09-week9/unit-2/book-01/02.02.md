# Subscribe to command data

In this step you will add code to listen for LED commands via `/<userID>/cmd/leds` and apply them to the LEDS on the sensehat. We will update the code to: 

- **subscribe** to `/<userID>/cmd/leds` in `on_connect`.
- Incoming messages will trigger `on_message`, which **parses JSON**, **normalises** the command to `"on"`/`"off"`, and **sets the LEDs**.

Add the following  just below the `TELEMETRY_TOPIC`declaration in `#------topics-----`

`CMD_LEDS_TOPIC  = f"/{USER_ID}/cmd/leds"`

Add the following helpers & callback functions  above `main()`:

```python
def apply_led_state(state: str) -> str:
    """Apply LED state and return normalized 'on'/'off'."""
    if state == "on":
        sense.clear(255, 255, 255)
        return "on"
    else:
        sense.clear(0, 0, 0)
        return "off"

def on_connect(c, u, f, rc):
    print("MQTT connected:", rc)
    c.subscribe(CMD_LEDS_TOPIC)

def on_message(c, u, msg):
    try:
        data = json.loads(msg.payload.decode("utf-8"))
        requested = "on" if data.get("state") == "on" else "off"
        actual = apply_led_state(requested)
        print("LED set via MQTT:", actual)
    except Exception as e:
        print("on_message error:", e)

client.on_connect = on_connect
client.on_message = on_message
```

Stop and start the sense_mqtt.py script for the changes to take affect.
