# Remote Network Traffic

In this step you will ping remote hosts (hosts not on your LAN) and examine the generated data from those pings. You can then compare this to what you observed in the last step.

+ In Wireshark, start capturing data again by clicking on the blue shark fin!  
![Start Capture](./img/shark.png)

+ If prompted to save current data, select *Click Continue without Saving*.
+ Ping the following three website URLs from the terminal: **google.ie, wit.ie, cisco.com** 
+ Stop capturing data by clicking the *Stop Capture* icon.
