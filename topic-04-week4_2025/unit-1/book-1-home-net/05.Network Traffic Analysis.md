# Network Traffic Analysis

Wireshark is a software protocol analyzer, or "packet sniffer" application. It can "captures" network traffic as it passes over a network interface and can decode and analyze its content according to its protocol specification. 
Uses include network troubleshooting, analysis, software and protocol development. 

You will now ping another PC on the private network and capture ICMP requests and replies in Wireshark. You will also look inside the frames captured for specific information.

### Start Wireshark and begin capturing data.

+ Start Wireshark on your host. 
+ Double-click the desired interface/adapter to start the packet capture. Make sure you select the correct interface used to connect to the LAN(It'll be the one showing the most activity...). 

![Wireshark Startup](./img/dir.png)

Network Traffic Information will start streaming down the top section in Wireshark. The data lines will appear in different colours based on the protocol.
Currently, we're only interested in ICMP (ping) traffic. 

+ Type "icmp" in the Filter box at the top of Wireshark and press Enter, or click the Apply button (arrow sign) to view only ICMP (ping) PDUs.  
![Wireshark Startup](./img/icmp.png)

This filter causes most or all data in the top window to disappear, but you are still capturing the traffic on the interface. 

+ Open command prompt window on your host and ping your Default Gateway.

![Ping Host from VM](./img/ping3.png)

+ Now stop capturing data by clicking the Stop Capture icon.

![Wireshark - Stop Capture](./img/stop.png)

## Examine Captured Data

Examine the data that was generated by the ping requests. Wireshark data is displayed in three sections: 1) The top section displays the list of PDU frames captured with a summary of the IP packet information listed; 2) the middle section lists PDU information for the frame selected in the top part of the screen and separates a captured PDU frame by its protocol layers; and 3) the bottom section displays the raw data of each layer. The raw data is displayed in both hexadecimal and decimal form.

+ Click the first ICMP request PDU frames in the top section of Wireshark. Notice that the Source column has your VM IP address, and the Destination column contains the IP address of the Host PC that you pinged.
+ With this PDU frame still selected in the top section, navigate to the middle section. Click the plus sign to the left of the Ethernet II row to view the destination and source MAC addresses.
