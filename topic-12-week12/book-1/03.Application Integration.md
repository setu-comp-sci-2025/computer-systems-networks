## Blynk Integration 

This step integrates the simulated sensor with the BLynk app developed int he last lab. However, the same approach could be used with other IoT technologies that we used in the module, such as MQTT, Thingspeak etc. 

+ On the Rasperry Pi, create a new file called ***blynk_pt_sensor.py*** in the same folder as sensor_listerner.py

+ Copy the following code (this is very similar to blynk_example1.py in the examples repo that we used in last used in last weeks lecture.

~~~python
import BlynkLib
from time import sleep
from sense_hat import SenseHat
from sensor_listener import SensorListener

#initialise SenseHAT
sense = SenseHat()
sense.clear()

# Initialise the Blynk instance
blynk = BlynkLib.Blynk("YOUR_TOKEN")

def motion_detected(data):
    print("motion detected")
    blynk.log_event("movement_event", "Motion Detected")
    blynk.virtual_write(0, 1)
    sleep(2)
    blynk.virtual_write(0, 0)
    
# Main loop to keep the Blynk connection alive and process events
if __name__ == "__main__":
    print("Blynk application started. Listening for Movement Events...")
    listener = SensorListener(port=5000)
    listener.callback = motion_detected
    listener.start()
    while True:
        blynk.run()  # Process Blynk events
~~~

+ Replace YOUR_TOKEN with the Blynk token for the Movement Detection device we developed in last weeks lab. 
+ Start the above Program and open the Web Dashboard for the Blynk device in a browser
+ Create another movement event in Packet tracer as before by dragging the mouse pointer across the motion sensor while Alt key is pressed. You should see the LED light up in Blynk and also receive a notification as a movement event was created. 

You now have successfully integrated a simulated sensor with a IoT platform. 
The same approach could be used with both Thingspeak and MQTT.
