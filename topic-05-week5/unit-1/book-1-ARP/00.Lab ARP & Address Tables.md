# ARP and Switch Address Tables 

ARP Requests · Switch Address Table · ARP Process

In this lab you will use Packet Tracer to gather PDU information in simulation mode and answer a series of questions about the data you collect. This will help you understand how IP address resolution works and how MAC addresses and IP addresses are used. You will also learn, through simulation, how a switch forwards frames using a MAC address table.

## Objectives

+ Simulate and understand an ARP Request
+ Simulate a switched network and explore a Switch MAC Address Table
+ Simulate the ARP Process in Remote Communications.  

## Prerequisites:

+ Packet Tracer
+ Valid Cisco ID
