# Port Security

Switches provide a "physical layer" security threat to networks. Devices can be connected to switches and protentially can gain access to the network. to address this threat, we will now shut down unused ports and restrict access to switch interface so that only the authorised devices can use it. 



## Shut Down Ports

Unused switch ports can be administratively shutdown to prevent unauthorised use. In this case, you will shut down the port connected to the Wireless Access Point.

+ Shutdown switch port fa2/1

~~~IOS
home-switch#conf term
Enter configuration commands, one per line.  End with CNTL/Z.
home-switch(config)#interface fa2/1
home-switch(config-if)#shutdown

%LINK-5-CHANGED: Interface FastEthernet4/1, changed state to administratively down
home-switch(config-if)#exit
home-switch#
~~~

The ``interface fa2/1`` command changes IOS to interface configuration sub-mode for fa2/1. And command entered in this mode is applies to fa2/1. Notice how the prompt chanes to ``(config-if)``

+ Notice that the connections indicate the shutdown (red colour). Try to ping any device from the college laptop connected to the WAP. It should fail.

Bring the port back up with the following command:

~~~
home-switch#conf t
Enter configuration commands, one per line.  End with CNTL/Z.
home-switch(config)#interface fa2/1
home-switch(config-if)#no shutdown
~~~



## Restrict Access to Port

The Internal web server is connected to switch port fa0/1. The following commands will restrict this port to accept frames from the server only.

~~~ios
home-switch#conf term
Enter configuration commands, one per line.  End with CNTL/Z.
home-switch(config)#interface fa0/1
home-switch(config-if)#switchport mode access
home-switch(config-if)#switchport port-security
home-switch(config-if)#switchport port-security mac-address sticky
home-switch(config-if)#switchport port-security maximum 1
home-switch(config-if)#switchport port-security violation shutdown
home-switch(config-if)#exit
~~~

The ``switchport port-security mac-address sticky`` command instructs the switch to **dynamically** learn the MAC address of the currently connected host (in this case the Server). 

The ``switchport port-security maximum 1``  command configures the maximum number of MAC addresses that can be received on the port. In this case it's just 1 (the Server)

The ``switchport port-security violation shutdown`` command configures the action taken when a frame from an unathorised device is received. The actions can be  protect, restrict, or shutdown interface commands. In this case, ``shutdown`` is the action chosen.
