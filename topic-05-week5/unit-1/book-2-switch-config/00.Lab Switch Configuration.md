# Basic Switch Configuration using Cisco CLI

Cisco IOS · Switch Configuration · Switch Port Security

This lab exercise simulates basic switch configuration whereby a network administrator will connect a switch console port using a console cable and Laptop. 

![](./img/console.png)

## Objectives

+ Connect to a switch using Console Cable
+ Configure a Cisco Switch using Cisco IOS
+ Save a switch configuration
+ Apply basic switch port security

## Prerequisites

+ Cisco PacketTracer
