# IP Addressing: Conversion

Use the online content/video to do the following conversions. Transcribing a 32 bit number from screen to paper is risky and boring! Perhaps open a spreadsheet and copy/paste the number into a cell, split the 32 bit address into 4 octets (stick a dot in the right place). Then you can create the "conversion table" used in the slides. 

### Binary to Dot Decimal

1. Convert the binary IPv4 address `11000000101010000000001000000001` into dot-decimal form
2. Convert the binary IPv4 address `10101100110100100010110000011010` into dot-decimal form

Find an online tool to check your answers



### Dot Decimal to Binary

1. Convert the dot-decimal IPv4 address `192.168.1.10` into binary
2. Convert the dot-decimal IPv4 address `10.32.5.255` into binary

Again, use a suitable online tool to check your answer
