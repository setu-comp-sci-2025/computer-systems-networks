# IP Addresses

Binary to Dot Decimal · Dot Decimal to Binary · Trouble Shooting an IP Network

It's important to understand how to convert IP addresses between binary and dot decimal. In reality there are plenty of online tools to do this. However, in order to design and troubleshoot IP networks, an understanding of Binary and Dot Decimal notation, and conversion between both, is beneficial.

## Objectives

In this lab, you will:

- Convert Binary IP Address to Dot Decimal 
- Convert Dot Decimal to Binary
- Calculate the network, broadcast address for an IP network using subnet mask
- Calculate the first and last IP address on a network
- Build a small network of 4 machines using a switch
- Troubleshoot a broken network

### Required Resources

- Packet Tracer
- Internet Connection
