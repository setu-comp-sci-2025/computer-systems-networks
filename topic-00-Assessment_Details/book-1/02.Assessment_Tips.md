## Options for grep

**-c**	counts the number of lines matching
e.g. 

```bash
num_matches=$(grep -icw "John" FullCustDetails)
```

- **-i** ignores case sensitivity in searching
- **-c** counts matching lines (prints a number)
- **-w** whole word "John" only
- **-v** if you wanted reverse grep and select lines not containing “John”

## Extracting the county details from the full record

- 	What's the output of the following command?

```bash
county=$(grep -i kilkenny CustDetails | awk '{print $1}')
echo $county
```

- but `awk` can search case-insensitively itself so we can simplify to:

```bash
county=$(awk 'tolower($0) ~ /kilkenny/ {print $1}' CustDetails)
```

or what about:

```bash
if [[ -f CustDetails ]]; then
  county=$(awk 'tolower($0) ~ /kilkenny/ {print $1; exit}' CustDetails)
  echo "$county"
else
  echo "CustDetails not found"
fi
```

Don't forget to adjust the field reference to the location of where YOU have the field stored

## **case** statement example.

```bash
read response
case $response in
    1) AddCust;;
    2) RemvCust;;
    5) exit;;
esac
```

## Redirection

To append to a file, use >>
e.g. 
```bash
echo $* >> Addrbook
```

## Comments

Ensure to add **comments** throughout your files to demonstrate what each of the sections functions are. 

You don't need to do this for every line/section of code but for the parts that you feel worthy of extra explaination i.e. how did you approach a particular issue, what is any problems did you encounter and how did you solve etc.
